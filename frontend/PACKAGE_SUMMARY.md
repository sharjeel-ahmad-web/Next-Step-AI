## 🚀 Quick Start

```bash
# 1. Extract and install
unzip nextstep-frontend-final.zip
cd nextstep-frontend-final
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env with your API URL

# 3. Start development
npm run dev
# Visit http://localhost:5173
```
